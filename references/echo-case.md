# 回声：技术参考案例

2026-10-01交付全片动态版：视频178秒，5340帧，1920×1080/30fps；容器178.005秒，H.264/AAC双声道48kHz。用户认可绘画审美与30秒动态样片，随后要求扩展到整片，17段均按内容加入运动。

工程在 assets/echo-remotion.zip，通过 bootstrap 解压。公开工程附有可编辑的场景与代码；原版私有核验文件和音轨未随包分发，任何新渲染都要重新验证。

| 时段 | 处理 |
|---|---|
| 0–16秒，两段 | 序和片名：烛火、天球仪、窗外星点、光尘，连续推进 |
| 16–27秒 | Transformer：铜轮、星光、帘布、衣摆、油灯，后退 |
| 27–36秒 | GPT-1：书房动作延续，向案头推进 |
| 36–45秒 | GPT-2：窗光、浮尘、衣料，靠近人物 |
| 45–57秒 | GPT-3：海浪纹理与泡沫，横移 |
| 57–66秒 | InstructGPT：纸面斜光、阴影、笔迹展开 |
| 66–84秒 | ChatGPT：河流、分层雪、街灯与暖窗，移向河岸 |
| 84–99秒 | GPT-4：双眼眨眼、暖光，靠近眼睛 |
| 99–113秒 | GPT-4o：水、衣料、帆与波形，后退横移 |
| 113–128秒 | o1：旅人两种脚步、道路位移与缩小、云雾 |
| 128–141秒 | GPT-5：柏树固定根部轻摆，天空与田野变化 |
| 141–149秒 | 谱系：斜光、树形细线、节点；修正英文注释与GPT-1重叠 |
| 149–160秒 | Astra：铜轮与内球、星光和帘布，靠近仪器 |
| 160–166秒 | Sol/Luna：城市河流与风雪，后退 |
| 166–174秒 | GPT-6.1 Sol：湖、反光、晨光、薄雾，提前引入星点 |
| 174–178秒 | 星点汇成ChatGPT，停留展示结句 |

方法要点：内部运动先于运镜；不改掉已认可的脸与画风；机械有支点、人物有脚底、水有岸线、星点有天空；预览通过后逐章落实全片；粒子连续收束；已减速的音轨不再减速。

原画和生成画来源在 art-sources.json，历史出处在 制作说明与史料.md，生成提示词随工程保存。星光采样采用工程内的确定性 Canvas 实现；局部画作运动为项目 Remotion Canvas 实现。
