# 画作内部运动

分析主体、遮挡、光源、地平线与视觉重心，每幕选择少量互相支持的动作。全局位移不能冒充人物动作或水流。

## 素材准备

主体离开原位置时准备干净背景与透明主体。两个姿态保持画幅、比例、光线与身份一致，只合成确实变化的局部。本环境有 image_gen 时用它编辑切图、干净底图与局部姿态；先检查原图，保存提示词和原图关系。原画纹理位移与图层合成用 Remotion Canvas，不用整张脸反复生成后的交叉淡化冒充眨眼。

| 场景 | 方法 | 关键 |
|---|---|---|
| 眼睛 | 原图固定，闭眼版本仅取双眼周围，柔边合成 | 对齐眼角与眉骨；闭合、短停、睁开分阶段；不是整脸叠化 |
| 旅人 | 清除原人物，透明主体放回道路；脚步与路径位移结合 | 脚底对应道路，随距离缩小，阴影跟随；手杖、帽子、包保持身份 |
| 衣料/帘布 | 遮罩内小幅、不同相位位移 | 固定身体、脸与接缝；幅度向固定端衰减 |
| 火与灯 | 独立火焰轮廓、白内核、暖辉光，多频率低幅变化 | 火焰接在烛芯上；环境光与火有关联，不让整图闪烁 |
| 水 | 分条采样原画，缓慢相位变化，以水面遮罩覆盖 | 避开岸、船与脸；远景幅度较小；反光独立轻闪 |
| 云雾/晨光 | 遮罩内轻微位移，漫射光变化，前后景浮尘 | 可按亮度与色差限制云区，保护岩石；尘点不满屏同速 |
| 雪/星点 | 场景坐标中的位置，按深度设置大小、速度与透明度 | 星点留在窗外或天空，雪有侧风；跟随世界而非字幕 |
| 树/田野 | 树梢幅度随高度增加，根部固定，田野更轻 | 避免连根滑动和原图/切图双边缘 |
| 天球仪/铜轮 | 独立切图，围绕支点转内球或改变外环投影 | 底座固定；前环遮挡内球，不让整套器械悬空旋转 |
| 档案纸 | 斜光、擦过的阴影、细线/笔迹展开，极小运镜 | 正文稳定可读，不强加风雪 |

## 实现细节

- 案例眨眼约0.39秒：0.13秒闭合、稍停、打开。按人物与节奏调整，不要求同一时刻。
- 透明切图常有孤立 alpha 噪点。边界盒采用有效 alpha 阈值与行/列像素计数，避免远处杂点把人物缩成细线。
- 两张走路姿态不要逐张透明覆盖，否则交叠区变暗或闪透明。案例在离屏画布分别加权，以 `lighter` 合成权重总和为1，最后一次绘制；仅替换腿部，保留上身。
- 遮罩柔化。位移幅度按原素材像素计，镜头缩放后观感不同，先检查实际帧。
- 顺序通常为干净底图 → 后方环境 → 主体/内球 → 前景遮挡 → 光尘 → 文字。不让星点透过窗框或水纹穿过脸。

## 运镜与衔接

在原图坐标中指定相机中心和缩放，平滑缓动并限制边缘，避免多幕都匀速放大。同一环境再出现时可用全局时间，使火光、雪和星点不重置；独有的表情与脚步用局部时间。

案例相邻 Sequence 有36帧重叠，上层约1.2秒淡入，不是一幕结束后直接切黑。更换衔接方式时同时检查相邻场景的时间范围与透明度。

近景检查帽顶与眼睛是否出框；素材宽高比改变时重算 safe camera。动作优秀但字幕遮眼或主体裁断也应修正。

## 星光汇字

等字体加载后将目标文字画在离屏 Canvas，采样 alpha 像素获得粒子目标。每粒子有种子决定的起点、延迟和弧线，由当前帧控制汇聚。成字后留稳定停留，只加少量残留星点与微闪。

从前一幕提前引入同组粒子，不在切换处重随机。新字样用 `measureText` 或实际 alpha 边界确定采样范围，不能用 ChatGPT 的英文宽度截断中文或长标题。是否淡黑按用户要求，默认收束在可读字形。
